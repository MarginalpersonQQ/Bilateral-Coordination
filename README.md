# This is a Bilateral Coordination Data Collection and Action Score Evaluation System.

## Main Program
The main program is implemented in "GUI_BLC_YU2_1.py".
This program can access the camera, display the camera and demostration video frame, and set the patient’s name.
 
## Action Score Evaluation System
The Action Score Evaluation System is implemented in "UI.py" and serves as the graphical user interface (GUI) of the system.
It enables users to select collected data files and performs action score evaluation based on the selected input.

## The Algorithm of the Evaluation System
The evaluation algorithm of the system is implemented in "Action3.0.py".
which defines the evaluation methods and computes the final action score.
